# Créer les données de démo

Demander le scénario, les questions à illustrer et le format souhaité.

1. Définir les tables utiles : par exemple produits, stocks, ventes et clients fictifs.
2. Générer un petit jeu cohérent avec une graine et des dates fixes.
3. Inclure un signal lié au scénario : rupture de stock, baisse des ventes ou retard.
4. Vérifier les relations entre tables et calculer un agrégat qui montre ce signal.

Fournir le générateur, les données, une courte description des colonnes et la
commande pour les régénérer. Signaler les vérifications non exécutées.
Ne pas utiliser de données client réelles. Demander confirmation avant toute
écriture distante ou tout remplacement de données existantes.
